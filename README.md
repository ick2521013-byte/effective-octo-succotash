# 市川おでかけ案内

千葉県市川市のスポットを紹介する、追加ツール不要の静的サイトです。

## ページ

- `index.html` — ニッケコルトンプラザ・大慶園と、おでかけモデルプラン
- `spots.html` — 里見公園、市川市動植物園、中山法華経寺、江戸川河川敷

`index.html` をブラウザーで開くと閲覧できます。`spots.html` の写真はサイト内に同梱しています。各写真の出典・作者・ライセンスは写真上のクレジットに記載しています。トップページの写真やWebフォント、外部リンクにはインターネット接続が必要です。

GitHub Pages は `main` ブランチへの push 後に自動で公開されます。
